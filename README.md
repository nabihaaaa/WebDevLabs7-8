**Author:** Nabiha Shah — 100874544  
**Course:** Web Dev  

## Overview

This lab involved building a VitePress site for the fictional web technology **PaperBeam**. The site includes a custom homepage, six content pages, a styled navbar, sidebar, and custom CSS theming.

## What I Did

### Part 1 — Basic VitePress Site

- Built a homepage with the PaperBeam logo, hero text, tagline, and two action buttons
- Added three fictional features with emoji icons (🦜 🍓 🌍)
- Created six pages total:
  - Root pages: `products.md`, `api.md`, `contact.md`
  - Learning subpages: `learning/docs.md`, `learning/cheatsheet.md`, `learning/blog.md`
- Across pages I included:
  - ✅ Markdown tables
  - ✅ Emojis
  - ✅ Custom containers (tip, warning, info)
  - ✅ Multiple heading levels
  - ✅ Ordered and unordered lists
  - ✅ Code snippets (JS + HTML)

### Part 2 — Extending the Default Theme

- Navbar with PaperBeam logo and title on the left
- Four nav items: Products, API, Learning (dropdown with 3 pages), Contact
- Sidebar on all non-home pages with two sections: **Overview** and **Learning**
- Custom CSS:
  - Primary button → green `#13b38e`
  - Secondary button → grey, turns pink `#ee9bdd` on hover
  - Active and hover states green across navbar and sidebar

## Tech Used

- [VitePress](https://vitepress.dev/)
- Markdown
- Custom CSS (no extra frameworks)
